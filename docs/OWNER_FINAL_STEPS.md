# Owner-only launch steps

1. Sign in to your Netlify team, confirm **Free** under **Usage & billing**, and authorize the Netlify GitHub App for `VHarshB/CommitCred`. Import `main` using the [deployment guide](NETLIFY_DEPLOYMENT.md#import-from-github).
2. Copy the assigned production HTTPS URL and make the intended project public. Keep the included address for a $0/year launch. CommitCred uses Netlify’s primary URL automatically.
3. Run the [live checks](NETLIFY_DEPLOYMENT.md#verify-a-live-report). If you want Google discovery, verify the actual origin in Search Console and submit `sitemap.xml` using the [SEO launch steps](SEO_LAUNCH.md).
