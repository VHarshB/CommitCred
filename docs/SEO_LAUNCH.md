# SEO launch

The home page serves the generator first. The three resources cover distinct intents: an editable GitHub sprint report example, evidence and limits of commit attribution, and how to write a sprint recap with blockers and next steps. The attribution guide follows GitHub’s explanation of linked commit authors and default branches. The sprint guide focuses on reporting outcomes and adapting next steps. [GitHub attribution reference](https://docs.github.com/en/account-and-profile/reference/profile-contributions-reference) [Scrum Guide](https://scrumguides.org/docs/scrumguide/v2020/2020-Scrum-Guide-US.pdf)

1. Copy the actual production HTTPS origin. Netlify uses its primary URL unless an explicit `SITE_URL` is configured. Run the production smoke script against it with the matching `COMMITCRED_EXPECTED_ORIGIN`. Check canonical URLs, the 1200×630 share card, sitemap, robots, and noindex on `/report`. Keep previews unconfigured for indexing.
2. In **Google Search Console → Add property**, select **URL prefix** for the assigned Netlify origin. For HTML tag verification, copy only the Google-provided content value into the public runtime variable `GOOGLE_SITE_VERIFICATION` in the Netlify project environment with function availability, redeploy, and click Verify. For a custom domain use a **Domain** property and add Google’s DNS TXT record. Use account-provided values and retain the verification record.
3. In the property’s **Sitemaps** report, submit `sitemap.xml`. In **URL Inspection**, test the live home page and guide URLs and request indexing for the launch pages once the live results show that they are accessible. Check the selected canonical after crawling.
4. Use [Schema Markup Validator](https://validator.schema.org/) and [Google Rich Results Test](https://search.google.com/test/rich-results) on the live site. The truthful WebApplication data has no reviews or ratings, so it is not eligible for Google’s software-app rich result. Keep schema accurate rather than adding invented ratings. [Google software app requirements](https://developers.google.com/search/docs/appearance/structured-data/software-app)
5. Review **Page indexing**, **Performance → Search results**, and **Core Web Vitals** weekly. Track impressions, clicks, queries, and landing pages. Verify the share preview on the real URL before announcing. Google controls crawl timing, index selection, and rankings. [Search Console guide](https://developers.google.com/search/docs/monitor-debug/search-console-start/)
